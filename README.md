# line-counter
 A C# program that counts the number of lines in your code project.

<br />

## Installation Approaches

### 1. With [.NET 9 Runtime](https://dot.net/download)
- Download the framework-dependent build from [Releases](https://github.com/prokenz101/line-counter/releases).

### 2. Without .NET 9 Runtime (not recommended)
- Download the self-contained build from [Releases](https://github.com/prokenz101/line-counter/releases).

<br />

## Use

Place the executable inside your project folder and run it from a terminal.

Specify the file extensions to include (e.g., .py, .cs, .js):

Example:

```bash
line-counter .py
```

This counts lines in every `.py` file in the current directory and its subdirectories.
